# Agiliza Guston

Este projeto consiste em um site simples desenvolvido para apresentar e distribuir a aplicação Agiliza Guston, uma solução em VBA voltada à otimização do processo de gestão de usuários e atribuição de funções no SAP S/4HANA.

# Estrutura do Projeto

O projeto é composto pelos seguintes arquivos:

index.html: Documento principal contendo a estrutura do site
css/styles.css: Arquivo de estilos responsável pelo layout e aparência visual
downloads/AGILIZA GUSTON - 2026.1.xlsm: Aplicação VBA disponível para download

# Sobre a Aplicação

Agiliza Guston é uma ferramenta desenvolvida em Excel com VBA (Visual Basic for Applications), responsável por automatizar a extração, consolidação e preparação de funções empresariais (roles) para atribuição em massa no SAP.

A aplicação processa documentos de Best Practices da SAP (.docx), extraindo dados e estruturando as informações em planilhas Excel.

# Funcionalidades
Extração de funções a partir de documentos da SAP
Consolidação automática e remoção de duplicidades
Geração de arquivos para atribuição em massa de funções

## Saídas Geradas
Arquivo completo: contém dados extraídos e consolidados
Arquivo parcial: contém apenas funções consolidadas
Arquivo de migração: estruturado para carga em massa no SAP

## Como Executar
Baixe ou clone o repositório
Abra o arquivo index.html no navegador
Realize o download do arquivo .xlsm disponível no site

## Como Utilizar

Após baixar a aplicação:

Habilite as macros no Excel
Clique em "Abrir App" para acessar a interface
Utilize uma das funções disponíveis:
Extrair
Adicionar
Carregar
